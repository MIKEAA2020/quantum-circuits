Deposited headline results

Quoted from the manuscript of record (v32), in its own register — exact statements are labeled exact, simulated statements are labeled simulated.

Exact · annealed replica ladder

Critical points at every replica number

n = 20.2338
n = 30.305(3)
n = 4≈0.383
n = 5≈0.47–0.48

Exact symmetry-resolved transfer-matrix computations; at n = 2 the model is exactly the triangular-lattice Ising model of Bao, Choi and Altman, with a closed-form critical point and a closed free-fermion spectrum. Potts universality at n = 3; marginal q = 4 behavior at n = 4.

At n = 5 the exact three-size test (L = 4, 6, 8) supports, at the three-size level, the first-order direction of the q = n-Potts identification — registered conditional: a fourth size (L = 10) completes or breaks it. The n = 5 value is a plausibility range, not an extrapolation.

No size extrapolation is applied at n = 5; the locator sequence 0.48 / 0.47 / 0.465 is monotone decreasing.

Simulated · quenched transition

Clifford finite-size-scaling benchmark

pc
0.1597(8)
ν
1.24(7)
α
1.55(7) bits  (= 0.54(2) nats per cut)

Hybrid random Clifford circuits, system sizes 16 ≤ L ≤ 512: crossings, data collapse, and bootstrap errors over 475,600 trajectories; the critical half-chain entropy scales as SL/2 = α ln L + b. The quenched point lies 0.074 below the exact annealed point pc(2)(2) = 0.2338.

Results of simulation, not theorems — quoted with systematic rather than statistical uncertainties; consistent with the literature (Gullans–Huse; Sierant).

The Gullans–Huse reference-qubit protocol — a different observable on trajectories disjoint from the I3 analysis (135,000 trajectories, independent seeds) — confirms the quenched critical point independently.

Quoted separately, and deliberately not combined with the adopted pc = 0.1597(8): different observable, different finite-size corrections.

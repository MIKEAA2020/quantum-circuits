## III. Steelman — the strongest available version of each weak part

**S1 — The corrected one-liner, sharpened to two clauses (in v5):**
- *Generativity clause:* generative power grows through falsifiable commitments **and** through unification, formalization, unification-with-heuristic-fertility.
- *Prediction clause:* empirical predictive power is **gated by** falsifiable surface — nothing bypasses the gate.
- *Lakatos clause:* a protected hard core is tolerable only while the program keeps a **novel-fact pipeline** open; a program with protected core and empty pipeline is degenerating, whatever its scope.
This is strictly stronger than both the original one-liner and the text's rewrite precisely because it is checkable at the program level (pipeline inspection, W5 annual re-audit).

**S2 — The inverse-problem application (E3.2), steelmanned (→ N1).**
Weak form: "find the simplest generative rule."
Strong form: *for each candidate structure, state the decoding problem formally*: minimize description length of (rule + residue) against a declared class of generative grammars (FT3 backstop); publish the grammar class and the residue — the residue is where the framework can be **wrong in a specific way** (a proposed rule that leaves structure unexplained dies). Instance family with mature literature: phyllotaxis packing, genetic-code error minimization, reaction-diffusion patterns.

**S3 — The cross-scale application (E3.3), steelmanned (→ N2).**
Weak form: "patterns recur across scales."
Strong form: the mature template is **universality** — Feigenbaum δ, RG universality classes: *proved* facts of "same exponent, different system." Directive: hunt recurrences with an identified invariant; the observed recurrence is evidence **only if** it persists after subtracting shared approximations (cautionary precedent: Zipf-type laws are multiply realized by non-self-similar mechanisms; recurrence ≠ common ground). This is the form/content honesty (E6) applied to P6.

**S4 — The point-circle generalization (E3.5), steelmanned (→ N3).**
The text says "generalize" and stops. The mathematics already contains the generalization and it is **spectacular for this framework**:
- **The degenerate circle is not a point.** Over ℂ, x²+y²=r² at r=0 factors as (x+iy)(x−iy)=0 — a *cone* (pair of null directions). The "point" is the **singularity at the apex**, not a point on the surface — a formal image of A not being an object among objects, *and* a direct bridge to twistor null-geometry (DP2/RP4).
- **The circle's lineage is constrained, not free:** Hopf fibrations S¹→S³→S², S³→S⁷→S⁴, S⁷→S¹⁵→S⁸ exist precisely for the normed division algebras ℝ, ℂ, ℍ, 𝕆 — and this same ladder underlies why supersymmetric strings live at D=3,4,6,10. So "generalize the point-circle" = a **real, checkable conjecture channel**: whether division-algebra/Hopf-lineage criteria filter unification candidates (octonionic standard-model projects are the existing arena).
This converts a gesture into the kind of node-derivation V6 demands.

**S5 — Self-modeling application (E3.6), steelmanned (→ N4).**
Weak form: "look for self-modeling."
Strong form: study systems whose endogenous model of themselves is functionally load-bearing (good-regulator principle; active-inference self-models; integrated-causal-structure measures; embedded-agent/Lawvere fixed-point constraints), and ask the polar question: **does the self-referential pole carry structural invariants that observer-free subsystems lack** — invariants of the observer-node as observer-node (the web-view question), not "consciousness from matter." Each sub-claim separately falsifiable; J3 discipline: none of this outputs "A" from the display.

**S6 — The soteriological coda (E5), steelmanned.** Prosaic core: at the level of doctrine it is P9 + the One (folded, provenanceful); at the level of program it must do no work. Strongest legitimate use: a *register note* marking the framework's telos vocabulary distinct from its proof vocabulary.
